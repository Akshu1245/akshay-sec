QRShield - QR phishing detection

Scans QR codes and links, then explains the warning signs before you pay, log in, or connect. Decodes images and camera frames on-device with jsQR - nothing is uploaded. Scores URLs and UPI payment details with transparent rules, and says "not checked" instead of "safe" when a check can't run.

  • PDF + text report export, local-only scan history
  • 46-test suite, camera permission handling with upload fallback

05 · tools

CLI security tools I wrote

Four small, sharp command-line tools. Each runs offline, has tests (36 passing across the set), all four are public on GitHub.

$ phishcheck https://example.com

URL phishing heuristics: lookalike domains, punycode, redirect chains, risky TLDs. Prints the reasons, not just a verdict.

source on github

$ headercheck github.com

Grades HTTP security headers (CSP, HSTS, X-Frame-Options and friends) with a fix hint per miss. Live run on github.com scored B.

source on github

$ passaudit "correct horse"

Password strength audit with pattern breakdown (repeats, sequences, dates, dictionary words) and crack-time estimates. Nothing leaves the machine.

source on github

$ logwatch auth.log

Watches auth logs for brute-force bursts and impossible-travel jumps, then prints a short incident summary you can paste into a report.

source on github
