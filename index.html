QRShield - QR phishing detection

Scans QR codes and links, then explains the warning signs before you pay, log in, or connect. Decodes images and camera frames in your browser with jsQR. Scores URLs and UPI payment details with transparent rules. An optional Google Web Risk lookup can submit a URL for a reputation check; the UI says "not checked" when that check is unavailable.

  • Rule-based risk scoring for URLs and UPI links; QR payload inspection for Wi-Fi data
  • PDF + text report export, local-only scan history
  • 46-test suite, camera permission handling with upload fallback

vite · jsqr · jspdf · vanilla js · vercel

05 · tools

CLI security tools I wrote

Four standalone Python tools with public source and tests. Check the repositories for usage, sample output and limitations.

$ python3 phishcheck.py https://example.com

URL phishing heuristics: lookalike domains, punycode, redirect chains, risky TLDs. Prints the reasons, not just a verdict.

source on github

Try the browser demo ↗

$ python3 headercheck.py github.com

Grades HTTP security headers (CSP, HSTS, X-Frame-Options and friends) with a fix hint per miss. Live run on github.com scored B.

source on github

Try the browser demo ↗

$ python3 passaudit.py "correct horse"

Password strength audit with pattern breakdown (repeats, sequences, dates, dictionary words) and crack-time estimates. Nothing leaves the machine.

source on github

Try the browser demo ↗

$ python3 logwatch.py auth.log

Checks SSH authentication logs for failed-login bursts and successful logins after repeated failures, then prints a short incident summary.

source on github
