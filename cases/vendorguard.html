VendorGuard AI

Making vendor-risk evidence readable.

An experimental vendor-risk and DPDP review dashboard.

View source ↗
PROJECT CONTEXTHackathon build · Team Rashi Innovators · hackathon project

THE PREMISE

What I wanted to solve

Vendor reviews often become disconnected spreadsheets. This project experiments with collecting evidence and showing the underlying factors behind a risk category.

THE BUILD

How it works

VendorGuard combines vendor onboarding, basic open-source intelligence, contract-rule mapping and evidence screens in one hackathon workflow. The code is public; a continuously available production deployment is not claimed.

IN THE REPOSITORY

What you can inspect

  • A six-step vendor onboarding demonstration.
  • DPDP-oriented contract checks and review screens.
  • Example public-breach back-tests and scoring views.
  • An executive dashboard that groups findings and lets reviewers inspect context.

BE HONEST ABOUT IT

Limitations and open questions

  • The output is not legal advice or a DPDP compliance certification.
  • Automated risk scores depend on the input and available evidence.
  • Hackathon integrations and demo fixtures are not proof of production readiness.
